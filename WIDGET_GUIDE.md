# PWA Widget Installation Guide

## How to Install the Widget

### 🤖 Android (Chrome)
1.  **Open the App**: Launch the portfolio (`https://mathewsb.in`) in Google Chrome.
2.  **Install App**: Tap the **Install** prompt or Go to **Menu (⋮) > Install App**.
3.  **Go to Home Screen**: Long-press on an empty space on your home screen.
4.  **Select Widgets**: Tap **Widgets**.
5.  **Find Chrome/Mathews B**: Scroll to find **Chrome** or the **Mathews B** app section.
6.  **Add Widget**: Drag and drop the **Mathews B** widget to your screen.
    *   *Note: Requires Android 8+ and depends on your Launcher's support.*

### 🖥️ Windows PC (Edge)
1.  **Open in Edge**: Navigate to the site.
2.  **Install App**: Click the **App Available** icon in the address bar > **Install**.
3.  **Open Sidebar**: Press `Ctrl + Shift + .` (period) to open the Edge Sidebar.
4.  **Customize**: Click the **+** icon at the bottom.
5.  **Add App**: Under **Apps**, find **Mathews B** and add it.

## 🎵 Music Playback Troubleshooting

**"Why isn't the music playing automatically?"**
*   **Mobile Policy**: Most mobile browsers block auto-playing audio to save data and battery.
*   **Solution**: You must **TAP** the Play button in the widget to start the stream.
*   **Background Play**: On some Android versions, if you lock the screen, the widget audio might pause. This is a system limitation for widgets to prevent battery drain. `Open App` for full uninterrupted experience.

## 🕒 Widget Updates
*   The widget updates automatically in the background. If you don't see the latest changes (like the 12-hour clock), try opening the app once to force a service worker update.
